Reset / uninstall

Clears all WhiteBox extension state — vault grant, settings, lock state, passphrase hash, danger toggles, bypass tier, conversation cache. Your vault folder on disk is left completely untouched. Files, observations, audit log, conversations, identity — all stay where they are. You can reconnect them later or open them in any text editor.

To fully uninstall: do this, then open chrome://extensions and remove WhiteBox. See UNINSTALL.md on GitHub for the complete walkthrough including MCP server cleanup.
