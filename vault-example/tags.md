# Tags

Canonical tags for observations in this vault. Agents prefer tags from the Active list when writing observations. New tags proposed by agents appear under Proposed — curate them on your own schedule (merge, rename, promote, or delete).

## Active

- `working-style` — how the user wants to be worked with (pace, register, pushback)
- `correction` — user corrected the agent
- `preference` — stated likes and dislikes
- `relationship:<name>` — observations specific to a named person
- `project:<slug>` — observations tied to a named project
- `health` — medical, sleep, energy, mood relevant to capacity
- `emotional-state` — temporary mood, stress, context
- `interest` — things the user is curious about or actively engaged with
- `conflict` — observations that contradict an existing stable fact or another observation
